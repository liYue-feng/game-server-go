注释一定要写好，新手需要参考学习。每个包、每个导出函数、每个关键设计决策都要有注释，解释 WHY 而非 WHAT。

**Why:** 项目定位为学习参考项目，代码本身就是文档。

**How to apply:** 所有 .go 文件的包注释、函数注释、设计决策注释都要充分。用中文写包级注释的关键部分，代码内注释用中文或英文均可。
