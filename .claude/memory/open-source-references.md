## 战斗系统参考

- **Unity_VampireSurvivors_Copy**: https://github.com/SikPang/Unity_VampireSurvivors_Copy
  - 参考：敌人AI、波次刷怪、升级选择、2D俯视角实现
  - 注意：原版是俯视角幸存者，本项目是横版ARPG，需要适配

## UI组件库

- **shuimo-ui-nightly**: https://www.npmjs.com/package/shuimo-ui-nightly
  - 水墨画风格的 Vue UI 组件库
  - 可参考其视觉设计语言（水墨纹理、笔触效果、配色方案）
  - Unity 端需要自己实现类似风格，不能直接用 Vue 组件
